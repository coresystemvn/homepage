Linux trong cái ngành sysadmin thì ai cũng hiểu xưa giờ là để cày cuốc phục vụ con người ta với vai trò hệ điều hành máy chủ. Giờ thì Linux cũng đã rất cải thiện cho UI/UX để có thể tiến sâu vào sân chơi desktop - nơi mà Microsoft Windows chiếm lĩnh gần như tuyệt đối thị phần

**Một hệ điều hành desktop cần gì?**

- Bảo mật - tất nhiên
- Đẹp và dễ sử dùng
- Ứng dụng phục vụ công việc đủ và đa dạng
- Với người Việt thì cũng cần phải gõ được tiếng Việt xuyên suốt mượt mà
- Có đủ phông chữ để làm việc cộng tác trong hệ sinh thái thuận lợi hơn

Vậy trừ một vài nhược điểm (có thể nhỏ, có thể không nhỏ) như gõ tiếng Việt, driver máy in và ứng dụng đặc thù chỉ có trên Windows

thì Linux ổn, rất ổn

![Minh họa](/images/blog/2026.june/20260627-kde-desktop.webp)

Và không chỉ khoe cái desktop đẹp, [CoreSystem](https://coresystem.vn) cũng có sẵn sàng phương án cài đặt chuẩn doanh nghiệp tốt nhất cho trải nghiệm lần đầu nhảy tàu từ Windows với đủ bộ font chữ Microsoft, bộ ứng dụng văn phòng, Google Chrome đã được thiết lập bảo mật cơ bản, gõ tiếng Việt ổn và một số ứng dụng hỗ trợ công việc văn phòng khác

- Tải bộ cài đặt từ mạng netinstall của Fedora [tại đây](https://download.fedoraproject.org/pub/fedora/linux/releases/44/Everything/x86_64/iso/Fedora-Everything-netinst-x86_64-44-1.7.iso)
- Dùng [rufus](https://rufus.ie/en/) hoặc [KDE Image Writer](https://apps.kde.org/isoimagewriter/) để ghi vào USB boot
- Boot từ USB, tại chọn lựa đầu tiên của màn hình boot => bấm e để thay đổi phương pháp cài (được tùy biến bởi CoreSystem)

```
Setparams 'Install Fedora 44'

    linux /images/pxeboot/vmlinuz inst.ks=https://coresystem.vn/files/fc44-smb.ks
    initrd /images/pxeboot/initrd.img
```
- Bấm F10 để tiến hành boot vào giao diện đồ họa với các tùy chọn gói cài đặt đã được tùy biến. Lưu ý tham số **inst.ks=https://coresystem.vn/files/fc44-smb.ks**
- Hoàn tất, restart máy và chuyển vào trạng thái tạo tài khoản lần đầu. Lúc này khoan hãy đăng nhập để cho hệ thống cài ứng dụng tự động, tinh chỉnh một số tham số và restart. Sau khi restart, đăng nhập và bắt đầu sử dụng. Tổng thời gian khoảng 25-30 phút cho tất cả

**Quy trình cài đặt**

Boot USB => chọn tham số => F10 => chọn ổ đĩa => Cài đặt => Reboot => Tạo tài khoản => Hệ thống reboot tự động => Sử dụng

** Quy trình cài tự động có gì **

- [File kickstarter](/files/fc44-smb.ks) quy định gói nào cài, gói nào bỏ giúp hệ điều hành chỉ tải những ứng dụng phù hợp, loại bỏ hoàn toàn ứng dụng rác (bloatware)

- Khi ở giai đoạn cuối của quá trình boot lần đầu, hệ thống sẽ tải file [post-setup.sh](/files/post-setup.sh) để quy định cài đặt bô sung cho lần khởi động sau

- Desktop mặc định của Fedora KDE là cực kỳ đa dạng trong tùy chỉnh, để các máy doanh nghiệp có trải nghiệm UI/UX không quá khác biệt với Windows, file [kde-config.txt](/files/kde-config.txt) được tải về trong quá trình cài
