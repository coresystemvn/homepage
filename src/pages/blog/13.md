Linux trong cái ngành sysadmin thì ai cũng hiểu xưa giờ là để cày cuốc phục vụ con người ta với vai trò hệ điều hành máy chủ. Giờ thì Linux cũng đã rất cải thiện cho UI/UX để có thể tiến sâu vào sân chơi desktop - nơi mà Microsoft Windows chiếm lĩnh gần như tuyệt đối thị phần

**Một hệ điều hành desktop cần gì?**

- Bảo mật - tất nhiên
- Đẹp và dễ sử dùng
- Ứng dụng phục vụ công việc đủ và đa dạng
- Với người Việt thì cũng cần phải gõ được tiếng Việt xuyên suốt mượt mà
- Có đủ phông chữ để làm việc cộng tác trong hệ sinh thái thuận lợi hơn

Vậy trừ một vài nhược điểm (có thể nhỏ, có thể không nhỏ) như gõ tiếng Việt chưa đủ tốt như Windows, driver máy in và ứng dụng đặc thù chỉ có trên Windows

thì Linux ổn, rất ổn

![Minh họa](/images/blog/2026.sep/20260905-fedora-desktop-winstyle.webp)

Và không chỉ khoe cái desktop đẹp, [CoreSystem](https://coresystem.vn) cũng có sẵn sàng phương án cài đặt chuẩn doanh nghiệp tốt nhất cho trải nghiệm lần đầu nhảy tàu từ Windows với đủ bộ font chữ Microsoft, bộ ứng dụng văn phòng, Google Chrome đã được thiết lập bảo mật cơ bản, gõ tiếng Việt tương đối ổn và một số ứng dụng hỗ trợ công việc văn phòng khác

- Tải bộ cài đặt từ mạng netinstall của Fedora [tại đây](https://download.fedoraproject.org/pub/fedora/linux/releases/44/Everything/x86_64/iso/Fedora-Everything-netinst-x86_64-44-1.7.iso)
- Dùng [rufus](https://rufus.ie/en/) hoặc [KDE Image Writer](https://apps.kde.org/isoimagewriter/) để ghi vào USB boot
- Boot từ USB, tại chọn lựa đầu tiên của màn hình boot => bấm e để thay đổi tham số cài đặt (được tùy biến bởi CoreSystem)

```
Setparams 'Install Fedora 44'
    linux /images/pxeboot/vmlinuz inst.stage2=hd:LABEL=Fedora-E-dvd-x86_64-44 inst.ks=https://coresystem.vn/files/f44-smb.ks
    initrd /images/pxeboot/initrd.img
```
- Bấm F10 để tiến hành boot vào giao diện đồ họa với các tùy chọn gói cài đặt đã được tùy biến. Lưu ý tham số **inst.ks=https://coresystem.vn/files/f44-smb.ks** phải trỏ đúng đến URL của file kickstart
- Ngoài ra, nếu file kickstart được copy vào thư mục gốc của đĩa ISO và ghi ra DVD tham số sẽ là **inst.ks=cdrom:/f44-smb.ks** hoặc nếu đĩa ISO được ghi ra USB bằng rufus thì **inst.ks=hd:LABEL=Fedora-E-dvd-x86_64-44:/f44-smb.ks**
- Ở giao diện cài đặt, các thiết lập mirror và gói cài đặt đã được file f44-smb.ks quy định chi tiết, chỉ cần chọn ổ đĩa cài đặt và tiến hành
- Hoàn tất, restart máy và chuyển vào trạng thái cài đặt hệ thống lần đầu. Lúc này máy chưa có sẵn tài khoản để đăng nhập tuy nhiên hệ thống đã được thiết lập cài ứng dụng tự động, tinh chỉnh một số tham số giao diện và restart. Sau khi restart, tạo tài khoản, đăng nhập và bắt đầu sử dụng. Tổng thời gian khoảng 20-30 phút cho tất cả

**Nâng cao**

- Làm chủ được quy trình cài đặt kickstarter để cài đặt Linux tự động rồi, mọi người cũng nên cân nhắc đến can thiệp boot menu **grub.cfg** để tạo nhiều profile ứng với nhiều file .ks ví dụ f44-smb.ks, f44-dev.ks, f44-sys.ks ứng với nhu cầu sử dụng của nhiều phòng ban khác nhau. (Công cụ hỗ trợ phía Windows có Notepad++ và Anyburn)
- Repository của Fedora trên cloud không phù hợp để cài hàng loạt máy, sync một local repo tại mạng LAN là phù hợp để cài số lượng (Công cụ hỗ trợ Linux chạy web server hosting local repo [bộ cài full package Fedora] và file cấu hình .ks)

**Các alias quy định sẵn**

```
alias hc='history -c && clear'
alias hce='history -c && exit' 
alias system-update='sudo dnf update' 
alias system-upgrade='sudo dnf upgrade'
alias system-info='fastfetch -s Title:Separator:Host:OS:BIOS:TPM:Kernel:Uptime:Display:CPU:GPU:PhysicalDisk:PhysicalMemory:Memory:Swap:Disk:Battery:PowerAdapter:Locale:Break:Colors'

```
Chức năng alias

```
 [1] xóa history & clear màn hình console
 [2] xóa history & thoát màn hình console
 [3] gọi cập nhật hệ thống
 [4] nâng cấp phiên bản nếu có
 [5] xem thông tin hệ thống fastfetch đã tùy biến
 ```

**Quy trình cài đặt**

Boot USB => chọn tham số *f44-smb.ks* => F10 => chọn ổ đĩa => Cài đặt => Reboot => Chờ setup lần đầu => Reboot tự động => Tạo tài khoản => Sử dụng

**Quy trình cài tự động có gì?**

- [File kickstarter](/files/f44-smb.ks) quy định gói nào cài, gói nào bỏ giúp hệ điều hành chỉ tải những ứng dụng phù hợp, loại bỏ hoàn toàn ứng dụng rác (bloatware)

- Khi ở giai đoạn cuối của quá trình boot lần đầu, hệ thống sẽ tải file [post-setup.sh](/files/post-setup.sh) để quy định cài đặt bô sung cho lần khởi động sau

- Desktop mặc định của Fedora KDE là cực kỳ đa dạng trong tùy chỉnh, để các máy doanh nghiệp có trải nghiệm UI/UX không quá khác biệt với Windows, file [kde-config.txt](/files/kde-config.txt) được tải về trong quá trình cài

**Mắc xương**

Lý thuyết thì luôn ngọt ngào cho đến khi thực tế vật chúng ta té ngửa! Cài rồi mới thấy để đến được kết quả cuối cùng nó nhiêu khê hơn bất kỳ ai có thể tưởng tượng, thật may cái này thì ```chúng mình đã "ôm" giúp mọi người``` để chỉ cần tải script về áp dụng cho công ty ngay và luôn - nice 👌
